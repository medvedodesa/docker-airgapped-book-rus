# Docker в закрытых контурах — скрипты

Скрипты к книге **«Docker в закрытых контурах: установка, безопасность и аттестация в изолированных средах»**.

Каждый скрипт привязан к конкретному разделу книги. Структура директорий повторяет нумерацию модулей и разделов.

## Структура

```
module-01/section-1.1/   — Изолированная среда: проверка изоляции
module-01/section-1.2/   — Архитектура: оценка готовности
module-01/section-1.3/   — Планирование: хранилище, IP, NTP
module-01/section-1.4/   — Подготовка к развёртыванию
module-02/               — Офлайн-установка Docker
module-03/               — Harbor: реестр образов
module-04/               — Безопасность контейнеров
module-05/               — Zero Trust
module-06/               — Сетевая изоляция
module-07/               — Vault: управление секретами
module-08/               — CI/CD в изолированной среде
module-09/               — Сборка образов
module-10/               — Мониторинг
module-11/               — Операции и обслуживание
module-12/               — Российская регуляторика и аттестация
```

## Использование

Все скрипты рассчитаны на bash 4+, тестировались на Ubuntu 22.04 и Astra Linux SE 1.7.

```bash
bash <имя-скрипта>.sh
```

Большинство скриптов выводят результат в формате `[PASS]` / `[WARN]` / `[FAIL]` и возвращают код выхода 1 при критических ошибках.
