## Ротация KV-секретов (пароли, токены)

- [ ] Определить список секретов для ротации (из матрицы ротации)
- [ ] Для каждого секрета: сгенерировать новое значение
- [ ] Записать в Vault: `bash rotate-static-secret.sh secret/prod/<сервис>/<ключ>`
- [ ] Убедиться что новая версия стала текущей: `vault kv get secret/prod/<сервис>/<ключ>`
- [ ] Перезапустить сервисы-потребители (или дождаться обновления Vault-агентом)
- [ ] Проверить работоспособность сервисов после ротации
- [ ] Обновить метаданные секрета с датой ротации

## Ротация AppRole Secret ID

- [ ] Для каждого AppRole: `bash generate-secret-id.sh <role_name>`
- [ ] Убедиться что Secret ID доставлен сервису через CI/CD
- [ ] Проверить что сервис успешно аутентифицируется с новым Secret ID

## Перевыпуск PKI-сертификатов (плановый)

- [ ] Проверить что Vault-агент работает: `systemctl status vault-agent`
- [ ] Инициировать обновление вручную (если нужно): перезапустить Vault-агент
- [ ] Убедиться что новый сертификат принят сервисом: `bash check-cert-expiry.sh`

## Ротация промежуточного CA (раз в год)

- [ ] Перевыпустить промежуточный CA: `vault write pki_int/intermediate/generate/internal ...`
- [ ] Подписать у корневого CA: `vault write pki/root/sign-intermediate ...`
- [ ] Загрузить подписанный сертификат: `vault write pki_int/intermediate/set-signed ...`
- [ ] Дождаться автоматического перевыпуска всех сервисных сертификатов
- [ ] Проверить CRL-точку: `bash check-crl-distribution.sh`

## Завершение

- [ ] Зафиксировать ротацию в журнале: дата, кто выполнил, что ротировано
- [ ] Обновить матрицу ротации с датой следующей плановой ротации
