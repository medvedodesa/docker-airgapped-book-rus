---

## На машине с интернетом

- [ ] Проверить официальность образа (Docker Official Image или Verified Publisher)
- [ ] Убедиться что Dockerfile образа публично доступен (открытый источник)
- [ ] Загрузить образ: `docker pull <образ>:<тег>`
- [ ] Зафиксировать SHA256: `docker inspect --format='{{index .RepoDigests 0}}' <образ>:<тег>`
- [ ] Запустить Trivy-сканирование: `trivy image --severity HIGH,CRITICAL <образ>:<тег>`
- [ ] Убедиться что нет CRITICAL-уязвимостей (или задокументировать исключения)
- [ ] Сохранить образ: `docker save <образ>:<тег> -o <образ-тег>.tar`
- [ ] Записать SHA256 архива: `sha256sum <образ-тег>.tar > <образ-тег>.tar.sha256`
- [ ] Записать результат Trivy в файл: `trivy image --format json ... > trivy-<образ-тег>.json`

## Перенос через шлюз

- [ ] Проверить содержимое носителя через антивирус (на шлюзовой станции)
- [ ] Проверить SHA256 после переноса: `sha256sum -c <образ-тег>.tar.sha256`
- [ ] Зафиксировать перенос в журнале переноса

## В закрытом контуре

- [ ] Загрузить образ: `docker load -i <образ-тег>.tar`
- [ ] Перетегировать для Harbor: `docker tag <образ>:<тег> harbor.internal.company.local/<проект>/<образ>:<тег>`
- [ ] Загрузить в Harbor: `docker push harbor.internal.company.local/<проект>/<образ>:<тег>`
- [ ] Проверить наличие в Harbor UI
- [ ] Убедиться что Harbor выполнил повторное сканирование
- [ ] Уведомить запросившего о доступности образа

## Документирование

- [ ] Записать в реестр базовых образов: источник, дата, дайджест, результат Trivy
- [ ] Сохранить файл `trivy-<образ-тег>.json` в репозиторий документации
