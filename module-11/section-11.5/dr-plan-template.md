## 4. Порядок восстановления

### Сценарий 1: Отказ одного хоста

1. Восстановить ОС на новом хосте (ISO-образ с USB)
2. Установить Docker: `bash install-docker-deb.sh`
3. Восстановить данные компонента с резервной копии
4. Переключить DNS/балансировщик на новый хост

### Сценарий 2: Потеря всех данных (пожар, затопление)

1. Получить офлайн-носители из резервного хранилища
2. Развернуть базовую инфраструктуру на резервных хостах
3. Выполнить: `bash full-restore-procedure.sh /media/backup-usb/latest`
4. Распечатать Vault (требует кворума держателей ключей)
5. Проверить: `bash morning-check.sh`

### Сценарий 3: Повреждение данных

1. Определить момент повреждения (журналы, Grafana)
2. Выбрать точку восстановления до повреждения
3. Восстановить конкретный компонент: `bash test-backup-restore.sh postgres /path/to/dump`
