## 4. Технические проверки перед внедрением

- [ ] `bash compliance-check.sh` — пройден без критических ошибок
- [ ] `bash pre-attestation-checklist.sh` — пройден
- [ ] Тестирование в тестовой среде выполнено
- [ ] Резервная копия создана перед изменением

---

## 5. Документирование

- [ ] Изменение зафиксировано в Git с описанием причины
- [ ] Технический паспорт обновлён (`bash generate-system-inventory.sh`)
- [ ] Схема сети обновлена (если изменялась сеть)
- [ ] Аттестационная лаборатория уведомлена (если требуется)

## 6. Решение

- [ ] **Изменение одобрено** — в рамках аттестата, внедрять
- [ ] **Изменение одобрено с условием** — согласовать с аттестационной лабораторией
- [ ] **Изменение отклонено** — не соответствует условиям аттестата
